## Reporting a Vulnerability

Hound takes security seriously. Hound runs static code analysis locally and processes OpenAPI specifications. It does not upload proprietary source code to external servers unless an explicit cloud LLM provider is enabled by the user.

If you discover a security vulnerability within Hound:

1. **Do not create a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by emailing `security@hound-watchdog.org`.
3. Include detailed steps to reproduce the issue, along with proof-of-concept code where possible.

We aim to acknowledge reports within 48 hours and provide patches promptly.
